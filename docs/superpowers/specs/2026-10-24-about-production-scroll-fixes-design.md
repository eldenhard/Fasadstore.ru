# Фотографии производства и исправление синего фона при прокрутке

## Цель

Добавить на страницу «О компании» реальные фотографии производства и устранить синие области,
которые появляются при переключении первого слайдера и при вертикальном overscroll страниц.

## Фотографии производства

- Использовать `20250212_151529.jpg` как кадр производственного процесса.
- Использовать `20250212_151613.jpg` как общий вид цеха.
- Разместить фотографии сразу после блока с текстом о производстве.
- На широком экране показывать два кадра рядом, на мобильном — друг под другом.
- Остальные похожие фотографии не добавлять, чтобы не дублировать содержание и не утяжелять страницу.

## Карусель

- Убрать горизонтальное перемещение слайдов, при котором входящий и выходящий слайды открывают фон
  контейнера.
- Использовать наложенные слайды с переходом по `opacity` длительностью 600 мс.
- Сохранить автопереключение, стрелки, индикаторы и блокировку повторного переключения во время
  анимации.

## Вертикальный browser overscroll

- Установить `overscroll-behavior-y: none` для `html` и `body`.
- Заменить синий глобальный фон `body` на белый.
- Белый фон служит fallback для браузеров, которые не полностью блокируют elastic overscroll.
- Темные секции сайта сохраняют собственные локальные фоны.

## Проверки

- Source-тест проверяет fade-переход и отсутствие `translateX` у слайдов.
- Source-тест проверяет глобальную настройку overscroll и белый fallback-фон.
- Source-тест проверяет обе фотографии и адаптивную сетку производства.
- Полный набор Node-тестов, `npm run build` и `git diff --check` должны завершиться успешно.

## Ограничения

- Полноценная горизонтальная анимация с отдельными состояниями входящего и выходящего слайда не
  реализуется: она не требуется дизайном и добавляет лишнее состояние.
- Галерея с полноэкранным просмотром фотографий не добавляется.
