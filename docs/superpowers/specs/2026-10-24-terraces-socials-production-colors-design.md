# Страница террас, социальные ссылки и production-цвета

## Цель

Добавить страницу «Остекление террас и патио» по предоставленному документу и фотографиям,
исправить расхождение цветов между dev- и production-сборкой, обновить заголовок сайта и заменить
устаревшие социальные каналы.

## Решение

### Production-цвета

- Отключить автоматический системный dark mode Nuxt UI, потому что у сайта есть только светлая
  дизайн-тема, а темные секции уже оформлены явно.
- Для выпадающего меню «Продукция» явно зафиксировать светлую поверхность и темный текст, чтобы
  читаемость не зависела от системной темы браузера.
- Не переписывать существующую палитру и не добавлять вторую тему.

### Заголовок и мобильное меню направлений

- Установить основной title сайта: «Алюминиевые системы Алютех».
- В заголовке каждого пункта мобильного аккордеона `.home-directions` добавить суффикс `ALUTECH`.
- Десктопные карточки не менять: бренд в них уже отображается отдельно.

### Страница террас

- Создать маршрут `/terraces` в стиле существующих продуктовых страниц.
- Использовать текст из документа без добавления новых маркетинговых формулировок.
- Вывести пять блоков в заданной последовательности:
  1. Раздвижные порталы — `/sliding-doors`.
  2. Входные группы и двери — `/doors`.
  3. Алюминиевые окна — `/windows`.
  4. Складные двери (гармошка) — `/sliding-doors/bf73`.
  5. Витражное остекление — `/facades`.
- Для блоков использовать пять предоставленных изображений в той же последовательности.
- Добавить маршрут в SEO, breadcrumbs, prerender и меню «Продукция».
- Карточка «Остекление террас и беседок» на главной ведет на `/terraces`.

### Социальные каналы

- Заменить YouTube на Rutube во всех текущих точках интерфейса, используя
  `https://rutube.ru/channel/53157696/`.
- Заменить WhatsApp на MAX во всех текущих точках интерфейса, используя
  `https://max.ru/join/mpPhGL6NOwn6T6zp06oKRePovLXW7n1rV0DECEXqFiE`.
- Обновить доступные подписи, иконки и hover-фоны под новые бренды.
- Не добавлять новую конфигурационную систему: ссылки используются только в нескольких
  существующих компонентах.

## Проверки

- Source-тесты Node проверяют маршрут, порядок секций и изображений, ссылки, title, мобильный
  суффикс, настройки темы и отсутствие старых социальных ссылок.
- `npm run build` проверяет TypeScript и production-сборку.
- `npm run generate` проверяет prerender новой страницы и итоговый HTML.

## Ограничения

- Отдельная переключаемая темная тема не создается.
- Тексты связанных продуктовых страниц не меняются.
- Форма обратной связи и новая логика социальных настроек не добавляются.
